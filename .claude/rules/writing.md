# ドキュメントの書き方

- 日本語で書く。
- 1 文は短くする。1 つの箇条書きに、1 つのことだけを書く。
- 比較は表にする。3 つ以上の並列は、箇条書きか表にする。
- ユーザーの言葉は、意味を変えずに残す（例：「作りたい」を「作れる」に変える）。言い換えたいときは、元の言葉と並べる。
- 見出しは「何が書いてあるか」がわかる名詞にする。
- ID の体系：

  | ID | 意味 | 置き場所 |
  |---|---|---|
  | P-番号 | 原則 | `docs/principles.md` |
  | L-領域番号-連番、L-UX-連番、L-B-連番 | 示唆 | `docs/requirements/lessons.md` |
  | F-領域-連番 | 機能要件の候補 | `docs/requirements/backlog.md` |
  | N-連番 | 非機能要件の候補 | `docs/requirements/backlog.md` |

  一度付けた ID は振り直さない。削除するときは「欠番」と書く。
- ファイル間のリンクは相対パスで書く。ファイル名を変えたら、リンクを検索して直す。
