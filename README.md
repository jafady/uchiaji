# uchiaji（うちあじ）

> いつのまにか、うちの味になる。
> 急かさない。決めつけない。でも、ちゃんと覚えている。

テレビやスーパーで出会った「やってみたい」を、その場で取っておく。食卓で「ちょっと塩足していいかも」と言ったことが、次に作るときには「うちの分量」になっている。探して集めるのではなく、出会ったものを育てる。

リポジトリの名前は、公開リポジトリとして作り直すときに tsukurou から変える（[docs/concept.md](docs/concept.md) の「名前」）。
