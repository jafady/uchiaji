# 使う側の道具（レシピ管理アプリ）

家庭の料理人が使うレシピ管理アプリのプロフィール。サービス同士の比較は [landscape.md](landscape.md)、調理中の UX をまとめたものは [cooking-ux.md](cooking-ux.md) にある。

## 調査について

- 調査日：2026-10-04
- 価格は取得時点の表示による（米国ストアの場合は米ドル）。
- Reddit の一次スレッドは確認できなかった。利用者の声は、App Store のレビュー、レビュー集約サイト、フォーラム、比較記事から集めた。

## プロフィールの書式

各サービスを次の順に書く。

1. 概要
2. 特徴的な機能
3. 活かす要素
4. 反面教師

## Paprika 3

**概要**

| 項目 | 内容 |
|---|---|
| 重心 | 集める→計画→買い物 |
| 公式の言葉 | "organize your recipes, make meal plans, and create grocery lists" |
| 価格 | プラットフォームごとの買い切り（iOS/Android $4.99、Mac/Windows $29.99） |
| 同期 | 独自のクラウド |

**特徴的な機能**

- 内蔵ブラウザとブックマークレットで取り込む。
- パントリーで食材と期限を管理する。
- `[recipe:名前]` の書式で、別のレシピへリンクできる。

**活かす要素**

- レシピを開いている間は、画面がスリープしない【事実】。
- 材料を線で消せる。現在の手順をハイライトできる【事実】。
- 手順文の中の時間を自動で検出する。タップするとタイマーが始まる【事実】。
- 分量のスケーリングと単位換算ができる。オフラインで閲覧できる【事実】。

**反面教師**

- 材料の消し込みや手順のハイライトが、画面を移ると消える【事実】。
- 材料と手順が別のタブにあり、調理中にタッチする回数が増える【声】。
- メジャーバージョンごと、プラットフォームごとに買い直しが必要。旧版が動かなくなり、データを失った例がある【声】。
- スケーリングで、括弧内の分量（「2 bags (16 oz)」）が変わらない【声】。
- レシピへのリンクは名前で引く。同じ名前があると、最初の 1 件が開く【事実】。
- 開発元の反応が鈍く、継続性が不安視されている【声】。
- 「作った日付つきのメモ」「調理履歴」を求める声がある【声】。uchiaji の領域 2 に需要があることの裏づけになる。

## Mela

**概要**

| 項目 | 内容 |
|---|---|
| 重心 | 集める＋作る |
| 公式の言葉 | "A simple, elegant and modern recipe manager for iOS and macOS that syncs with iCloud" |
| 価格 | 無料ダウンロード＋アプリ内課金の買い切り（iOS $4.99、Mac $9.99）。サブスクはない |
| 同期 | iCloud。Apple 専用 |
| 開発 | Silvio Rizzi 氏の個人開発（Reeder の作者）。プライバシーラベルは「データを収集しない」 |
| 最新版 | 2.6.2（2025-06）。2026-06 に、大型の無償アップデートを開発中と告知 |
| 評価 | 米国 iOS 4.6（876 件）、日本 iOS 4.2（11 件） |

**受賞と評価**【事実】

- Apple Design Awards 2025：Interaction 部門のファイナリスト。
- App Store Editors' Choice。講評は "view instructions using the gorgeous cook mode"。
- MacStories Selects 2021：Best Design を受賞。講評は "Everything is easy to read at a glance and uses just the right amount of color"。

**特徴的な機能**

- ブログを RSS で購読できる。
- Web 検索、動画の説明文（YouTube・Instagram・TikTok）、カメラや OCR からも取り込める。
- Apple 純正の仕組みを積極的に使う。
  - 買い物リストはリマインダー、献立はカレンダーで管理する。
  - OCR は Vision を使う。
  - タイマーは Live Activities と Dynamic Island に表示する。

### 何が「美しい」のか

装飾を足して見せるのではなく、**表示するものを減らし、文字組みを整え、色を 1 色に絞っている**ことが「エレガント」という評価の中身と考えられる【推測】。比較の相手は、広告や前置きで散らかったレシピサイトである【声】。

- **色**：アクセントは明るい黄色の 1 色。Cook / Groceries / Scale のボタンだけを黄色にする。背景は白、文字は黒。ダークモードもある【事実】。
- **タイポグラフィ**
  - 材料の分量は太字、品種などの補足は斜体にする。拾い読みしやすい【事実】。
  - 書体と文字サイズの具体的な値は未確認。
- **レイアウト**：端末の画面幅に合わせて列を変える【事実】。

  | 端末 | 構成 |
  |---|---|
  | iPhone | 1 列。写真→説明→材料→手順の順に縦に並ぶ |
  | iPad Air | 2 ペイン。左に説明と手順、右に写真と材料 |
  | 大きい iPad / Mac | 3 列。左に写真と説明、中央に手順、右に材料。「画面を使い切っても散らからない」と評された |

- **レシピ画面の並び**：上から次の順に並ぶ【事実】。
  1. 料理名と出典リンク
  2. 人数と所要時間
  3. 黄色のボタン（Cook / Groceries / Scale）
  4. 写真
  5. 説明
  6. 材料
  7. 手順
- **開発者の姿勢**：次の大型アップデートについて、開発者は「ガラス素材で装飾するのではなく、コンテンツを前面に浮かせる」と述べている。コンテンツを最優先する姿勢が読み取れる【事実・推測】。

### 調理モード

- **フォーカスモード方式**【事実】
  - 全画面で、手順と材料だけを大きな文字で表示する。
  - 現在の手順を太字で強調し、前後の手順は薄いグレーで見えたままにする。
  - 1 手順ずつ紙芝居のように切り替える方式ではない。前後の手順が見えるので、「次に何が来るか」の見通しが残る。
  - 手順の中の分量や時間の表記も、適切なタイミングで強調される（Apple Design Awards の講評）。
- **材料の配置**【事実】
  - iPad と Mac では、左に手順、右に材料を常に表示する。
  - iPhone では、左右のスワイプで手順と材料を切り替える。
  - 材料はチェックして消し込める。
- **操作**
  - キーボードの Space と ↓ で次の手順、↑ で前の手順へ移る【事実】。
  - タッチでの手順送りの方式は未確認。
  - 音声操作やハンズフリー操作はない。
- **タイマー**【事実】
  - 手順の中の時間表記をタップすると、タイマーが始まる。
  - 複数のタイマーを同時に動かせる。
  - ロック画面と Dynamic Island にも表示される。
- **複数のレシピ**：調理モードに複数のレシピを追加し、切り替えられる【事実】。

### 取り込みと編集

- **取り込み**
  - 構造化データの材料と手順だけを拾う。そのため、前置きや広告は自然に落ちる【推測】。
  - 構造化データがないサイトでは、端末上の機械学習による取り込みに切り替える【事実】。
  - TikTok からの抽出の成功率は約 7 割だった（MacStories）。
- **アプリ内ブラウザ**：レシピを検出すると、整形したレシピをその場でプレビューする【事実】。
- **編集画面**【事実】
  - Markdown の一部（見出し・太字・斜体）が使える。
  - 行頭に `#` を付けると、材料や手順をグループに分けられる（「ソース」「生地」など）。
  - 材料は、入力した文字列から分量と単位を自動で判別する。
- **整理**：カテゴリ、お気に入り、「作りたい」の 3 つで整理する【事実】。

**活かす要素**

- 現在の手順を強調し、前後の手順は薄く見えたままにする（フォーカスモード方式）。
- 手順の中の時間表記をタップすると、タイマーが始まる。複数のタイマーを並行して動かせる。
- 材料リストでも手順文でも、分量を太字にする。
- アクセントを 1 色に絞り、表示するものを減らす。
- 材料と手順を見出し行でグループに分ける。日本語レシピの「A（合わせ調味料）」と相性がよく、部品化（領域 3）の手がかりにもなる。
- 取り込む前に、解析結果をプレビューで確認できる。

**反面教師**

- 画面スリープの防止がない（2022 年のレビュー。現行版は未確認）【声】。
- 別のアプリに切り替えると、どこまで進んだかを忘れる【声】。
- 調理中に、複数のレシピを行き来しにくい【声】。
- 調理モードやタイマーが目立たず、リリースノートを読んだ人しか気づかない、という指摘がある（出典の本文は未確認）。
- カテゴリをまとめて編集できない。ラベルを削除できない。入れ子のタグがない【声】。
- **日本語に対応していない**：UI と単位の解析は英・独・仏・伊の 4 言語だけ。「大さじ・小さじを認識しない」というレビューがある【事実・声】。
- 前置きや広告を除けることが価値の中心になっている。作り手の送客の観点では、そのまま真似できない（[case-studies.md](case-studies.md)）。

## Crouton

**概要**

| 項目 | 内容 |
|---|---|
| 重心 | 作る＋計画 |
| 公式の言葉 | "A home for your favourite recipes, from wherever you find them" |
| 価格 | 無料（件数に上限あり）、Plus は買い切り $24.99、AI 機能の Discover は年 $14.99 |
| 同期 | iCloud。Apple 専用 |

**活かす要素**

- 顔ジェスチャーで操作できる。右ウインクで次、左ウインクで前、口を開けると材料一覧が開閉する【事実】。
- タイマーを自動で検出する。Apple Watch から操作できる【事実】。
- 人数だけでなく、特定の材料の量を基準にスケーリングできる【事実】。
- 作り置きのバッジを付けられる。Bluetooth スケールと連携できる【事実】。
- PDF、Markdown、テキスト、schema.org JSON-LD で書き出せる【事実】。
- AI で料理本の写真から取り込める【事実・声】。

**反面教師**

- ジェスチャーの認識が不安定なことがある【声】。
- 手書きの読み取りが苦手で、手直しが必要【声】。
- 値上げに反発が出た【声】。

| 公式の言葉 | "World's most popular recipe organizer" |

## Cooklang

**概要**

| 項目 | 内容 |
|---|---|
| 重心 | 書く→作る・買い物 |
| 公式の言葉 | "A simple text format for recipes that both cooks and computers understand" |
| 価格 | OSS。同期の Cook Cloud は月 €4.99 |

**活かす要素**

- 人が読める文章のまま、機械も扱える記法になっている。材料は `@材料{量%単位}`、道具は `#道具`、タイマーは `~{時間}` と書く【事実】。
- 別のレシピを量つきで参照できる（`@./sauces/teriyaki{100%ml}`）。部品化にそのまま使える【事実】。
- データベースもロックインもない。同期は iCloud・Dropbox・Syncthing から選べる【事実】。
- アプリは大きな文字で表示し、スワイプで手順を送る。タイマーはバックグラウンドでも通知する。買い物リストは売り場順に並ぶ【事実】。
- 有料化したとき、既存ユーザーは無料のまま据え置いた【事実】。

**反面教師**

- 記法を一般の人に書かせるのは無理がある【推測】。内部形式や書き出し形式として使い、入力は UI か AI で行うのが妥当。
