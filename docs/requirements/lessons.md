# 既存サービスからの示唆（領域別）

[research/](../research/) の調査から、tsukurou の機能の領域（2026-11-04 まで「5 つの柱」と呼んでいたもの）と使う場面ごとに「活かす要素」と「避ける要素」を抜き出した。要件や設計を判断するときは、ここを参照する。

ID の付け方：

- `L-領域番号-連番`：機能の領域ごとの示唆（ID は振り直さない。番号は [concept.md](../concept.md) の「機能の領域」を指す）
- `L-UX-連番`：調理中の UX の示唆
- `L-B-連番`：事業・運営面の示唆

要件側（[backlog.md](backlog.md)）から、この ID で参照する。

## 領域 1：由来を問わず受け取る

| ID | 区分 | 示唆 | 根拠 |
|---|---|---|---|
| L-1-01 | 活かす | 取り込み経路を多く持つ：URL、共有シート、スクショ・手書き写真、動画の説明文・音声、メモアプリ、手入力 | Mela, Crouton, ReciMe, クリップレシピ |
| L-1-02 | 活かす | 保存する前にプレビューして編集できるようにする | Mela, Pestle |
| L-1-03 | 活かす | 構造化データを先に試し、失敗したら AI で補う二段構えにする | Mela |
| L-1-04 | 活かす | 取り込んだ原文を保持し、解析が誤っても戻れるようにする | Mealie |
| L-1-05 | 活かす | 日本のサイトは、構造化データの有無と品質がまちまち。サイト別の補正か、HTML の解析が必要になる | import-sources.md |
| L-1-06 | 避ける | 取り込み回数で課金する | ReciMe, クックパッド |
| L-1-07 | 避ける | 取り込みに失敗したまま、誤ったデータを黙って保存する | ReciMe |
| L-1-08 | 避ける | 手書きの読み取り精度を過信する。手直しを前提にした UI にする | Crouton |
| L-1-09 | 独自 | 未完成のレシピ（材料が不明、目分量、店の味を推定中）を正規の状態として扱う | 競合になし |

## 領域 2：料理単位でまとめ、自分版を育てる

| ID | 区分 | 示唆 | 根拠 |
|---|---|---|---|
| L-2-01 | 活かす | 作った記録をタイムラインで残す（日時・コメント・写真）。「最後に作った日」を持つ | Mealie |
| L-2-02 | 活かす | 日付つきメモと調理履歴には需要がある | Paprika への要望 |
| L-2-03 | 避ける | メモ欄が 1 つだけで、レシピ本体と混ざる | 多くのアプリ |
| L-2-04 | 独自 | 版管理（差分を見る、戻す、試作版を分岐して採否を決める）を持つ競合はない。最大の差別化点 | 競合になし |
| L-2-05 | 独自 | 同じ料理の複数のレシピを並べて比べ、自分版にまとめる機能はない | 競合になし |

## 領域 3：部品化

| ID | 区分 | 示唆 | 根拠 |
|---|---|---|---|
| L-3-01 | 活かす | レシピから別のレシピ（部品）を量つきで参照する | Cooklang, Tandoor, Paprika |

| L-3-03 | 避ける | 名前だけで参照する。同じ名前が複数あると誤って解決する | Paprika |

| L-3-05 | 独自 | 取り込んだレシピからタレを切り出す機能や、「いつものタレ」に置き換える機能は、競合にない | 競合になし |

## 調理中の UX（場面「作る」）

| ID | 示唆 | 根拠 |
|---|---|---|
| L-UX-01 | 画面のスリープを防ぐ | Paprika, ReciMe |
| L-UX-02 | 大きな文字で、現在の手順を強調する。前後の手順は薄く見えたままにし、分量は太字にする | Mela（フォーカスモード）, Cooklang |
| L-UX-03 | 材料と手順を同時に見られるようにする。スマホの縦画面なら、手順カードにその手順の材料と分量を入れる | Mela, Pestle。別タブ方式は Paprika の反面教師 |
| L-UX-04 | 手が汚れていても操作できる（画面の大きな領域をタップ、スワイプ、音声）。「戻る」を必ず用意する | Pestle, Crouton |
| L-UX-05 | 手順文からタイマーを自動で見つける。並行して動かせ、ラベルを付け、通知する | Paprika, Pestle, Crouton |
| L-UX-06 | 材料の消し込み・現在の手順・タイマーを、画面やアプリを移っても保持し、戻ったときに復元する | Paprika・Mela の反面教師 |
| L-UX-07 | スケーリングで括弧内などの変換漏れを出さない | Paprika の反面教師 |
| L-UX-08 | 複数の料理を並行して作れる。切り替えをわかりやすくする | Mela |
| L-UX-09 | オフラインで使える | Paprika, クリップレシピ |
| L-UX-10 | 作り終えたら振り返り（記録・メモ）へつなぐ | Mealie を発展させる |
| L-UX-11 | 調理モードの入口を目立たせる | Mela の反面教師 |
| L-UX-12 | 日本語の時間表記（5分、1時間半、10〜15分）と分量表記（大さじ・少々・適量など）を解析する | Mela など海外アプリは日本語に未対応 |
| L-UX-13 | アクセントを 1 色に絞り、表示するものを減らす。材料と手順を見出しでグループに分ける | Mela |

## 事業・運営面

| ID | 示唆 | 根拠 |
|---|---|---|
| L-B-01 | 買い直しや値上げは反発を招く。課金するなら、既存ユーザーを据え置く配慮をする | Paprika, Crouton, Cooklang |
| L-B-02 | 開発元の反応の速さは評価される。反応が鈍いと、継続性が不安視される | Pestle, Paprika |
| L-B-03 | 特定の発信手段に依存した器は、発信の場が移ると不要になる | レシピブログ |
